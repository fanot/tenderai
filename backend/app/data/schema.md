# Схема карточки закупки

Внутренний формат, к которому приводятся данные любого источника
(`tenders.json`, выгрузка ЕИС, коммерческий агрегатор).

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Внутренний идентификатор (`T-0001`) |
| `registry_number` | string | Реестровый номер извещения в ЕИС |
| `subject` | string | Предмет закупки (наименование объекта закупки) |
| `description` | string | Развёрнутое описание: способ, сроки, оплата, требования |
| `law` | string | `44-ФЗ` или `223-ФЗ` |
| `procedure` | string | Способ определения поставщика |
| `platform` | string | Электронная торговая площадка |
| `customer` | string | Наименование заказчика |
| `customer_inn` | string | ИНН заказчика |
| `region` | string | Регион поставки |
| `region_code` | string | Код субъекта РФ |
| `category` | string | Внутренняя категория (используется в фильтрах) |
| `okpd2` | string | Код ОКПД2 |
| `nmck` | number | Начальная (максимальная) цена контракта, ₽ |
| `currency` | string | Валюта, по умолчанию `RUB` |
| `application_security_pct` | number | Обеспечение заявки, % НМЦК |
| `contract_security_pct` | number | Обеспечение исполнения контракта, % НМЦК |
| `published_at` | string (ISO date) | Дата публикации извещения |
| `deadline_at` | string (ISO date) | Дата окончания приёма заявок |
| `status` | string | `Подача заявок`, `Работа комиссии`, `Завершена`, `Отменена` |
| `smp_only` | boolean | Закупка только для СМП и СОНКО (ст. 30 44-ФЗ) |
| `requirements` | string[] | Требования к участникам |
| `advantages` | string | Преимущества, ограничения и запреты (нацрежим, ПП РФ) |
| `url` | string | Ссылка на карточку закупки в ЕИС |

## Индексация

Каждая карточка разбивается на три смысловых чанка (`app/rag/chunking.py`):

1. **Карточка закупки** — предмет, заказчик, регион, категория, закон, площадка, номер.
2. **Условия и сроки** — НМЦК, обеспечения, даты публикации и окончания приёма, статус, преференции.
3. **Требования и описание** — требования к участникам и полное описание закупки.

Разбиение по смысловым секциям (а не по фиксированному числу символов) позволяет
ассистенту ссылаться на конкретный раздел карточки, а не на произвольный отрезок текста.

## Проверка данных

`app/data/eis_adapter.py::validate` проверяет полноту обязательных полей и
уникальность идентификаторов. Вызывайте её после любой загрузки данных из
внешнего источника.
